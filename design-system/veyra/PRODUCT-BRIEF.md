# Veyra｜Product UI Brief

## 产品任务
- 产品类型：AI 游戏创作工作台与可玩演示
- 核心用户：面试展示者、独立游戏创作者、AI 产品体验评审者
- 高频任务：输入创意、启动生成、查看流水线、试玩产物、检查资产与证明
- 首要 CTA：启动铸造
- 高风险误操作：误把静态视觉状态当成真实生成结果；因此明确标注当前为交互演示

## 内容与状态
- 首屏必须出现：产品价值、任务简报、六阶段流水线、可玩游戏舱
- 数据/来源状态：仅显示本地真实交互状态，不展示虚构用户量或效果指标
- 状态覆盖：空输入错误、生成加载、完成成功、按钮禁用、暂停/恢复

## 品牌与视觉
- 品牌性格：深海工程感、克制、可靠、敏捷
- 版式签名：潜艇任务控制台式非对称模块网格
- 信息签名：从创意到验证的六段证明链
- 交互签名：可直接驾驶小鲨鱼的声呐试玩舱
- 明确避免：紫粉 AI 渐变、同质化玻璃卡、无意义数据和装饰性 emoji

## 设备与无障碍
- 视口：390 / 768 / 1024 / 1440
- 键盘与焦点：必须验收
- 减少动效：必须支持
- 目标标准：WCAG 2.2 AA 基础项
